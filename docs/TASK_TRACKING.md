## 📋 任务概述

根据 sm-js-bc v0.4.0 版本的功能，对 sm-py-bc 进行功能对齐。本文档用于跟踪开发进度和决策记录。

### sm-js-bc v0.4.0 主要功能

1. **API 一致性改进** (v0.3.1)
   - SM3Digest.reset(Memoable) 方法重载
   - SM2Engine.Mode 静态属性
   - SM2Signer 保护方法增强

2. **HMAC-SM3** (v0.4.0)
   - 基于 SM3 的消息认证码
   - 完全兼容 Bouncy Castle Java

3. **ZUC 流密码** (v0.4.0)
   - ZUC-128 引擎
   - ZUC-256 引擎
   - ZUC-128 MAC
   - ZUC-256 MAC

4. **PKI 支持** (v0.4.0)
   - ASN.1 编码/解码
   - PKCS#8 密钥编码
   - X.509 证书支持
   - 证书链验证

## 📝 决策记录

### 2025-12-08: 初始任务分析

**决策**: 
1. v0.2.0 功能已全部完成，无需重复实现
2. 专注于 v0.3.0 的 ZUC 完整实现
3. PKI 支持推迟到 v0.4.0

**理由**:
- v0.2.0 代码已存在且测试通过
- ZUC 是 sm-js-bc v0.4.0 的核心新功能
- PKI 实现复杂度高，需要专门时间

### 2025-12-08: ZUC 实现策略

**决策**: 按照以下顺序实现
1. ✅ ZUC-256 引擎（扩展现有 ZUC-128）
2. ✅ ZUC-128 MAC（基于 ZUC-128 引擎）
3. ✅ ZUC-256 MAC（基于 ZUC-256 引擎）

**理由**:
- 渐进式开发，减少风险
- 每个组件可以独立测试
- 后续组件依赖前面的基础

**结果**: 全部实现完成，所有测试通过 (584/585 passing)
