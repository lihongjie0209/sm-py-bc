## 🎓 Technical Decisions

### Decision 1: Python Naming Conventions

**Choice**: Use snake_case for method names (not camelCase)

**Rationale**:
- PEP 8 standard mandates snake_case
- Ecosystem consistency with standard library
- Better readability in Python context
- Tool support expects snake_case

**Impact**: Methods like `getAlgorithmName()` → `get_algorithm_name()`

### Decision 2: HMAC Implementation Scope

**Choice**: Implement HMAC with any Digest support (not just SM3)

**Rationale**:
- Matches Bouncy Castle Java design
- More flexible and reusable
- Enables future digest algorithms
- No additional complexity

**Impact**: `HMac(digest)` works with any digest implementation

### Decision 3: ZUC and PKI Deferral

**Choice**: Document but defer ZUC cipher and PKI support

**Rationale**:
- Large scope (30-40 hours additional work)
- Not critical for immediate v0.2.0 release
- HMAC-SM3 provides more immediate value
- Can be added in future versions

**Impact**: Documented in "Future Enhancements" section
